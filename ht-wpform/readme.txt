HT Form Widget for Elementor and WPForms allows you to easily display WPForms forms using Elementor with full styling control.

== Description ==
HT Form Widget for Elementor and WPForms is an Elementor addon that allows you to easily add WPForms forms to your pages using a drag-and-drop widget. Simply select your form from a dropdown and customize every aspect of its appearance without writing any code.

**Required Plugin:** [WPForms](https://wordpress.org/plugins/wpforms-lite/)

== Features ==

**Easy Form Integration**
* Select any WPForms form from a dropdown list
* Drag and drop widget placement in Elementor
* Show or hide form title and description

**Complete Styling Control**
* **Title Styling** - Customize color, typography, padding, margin, border, and border radius
* **Description Styling** - Full control over description appearance
* **Label Styling** - Style form labels with background color, text color, typography, and spacing
* **Sub-label Styling** - Separate styling for sub-labels
* **Required Field Indicator** - Custom color for required field markers

**Input & Textarea Styling**
* Background and text color customization
* Typography controls (font family, size, weight)
* Height adjustment for input fields and textareas
* Padding, margin, and border controls
* Border radius for rounded corners

**Submit Button Styling**
* Full-width button option
* Custom width and height controls
* Button position (left, center, right)
* Normal and hover state styling
* Box shadow effects
* Complete typography control

**Responsive Design**
* All styling options support desktop, tablet, and mobile views
* Create forms that look great on any device

== Installation ==
This section describes how to install the HT Form Widget for Elementor and WPForms plugin and get it working.

= Install from WordPress Dashboard =
1. Go to the WordPress Dashboard "Add New Plugin" section.
2. Search for "HT Form Widget for Elementor and WPForms".
3. Install, then Activate it.

= Manual Installation =
1. Upload the `ht-wpform` folder to the `/wp-content/plugins/` directory
2. Activate the plugin through the 'Plugins' menu in WordPress

= Requirements =
* WordPress 5.0 or higher
* Elementor 2.0.0 or higher
* WPForms Lite or WPForms Pro
